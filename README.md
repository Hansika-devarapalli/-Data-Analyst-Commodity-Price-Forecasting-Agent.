# Silver Commodity Price Forecasting and Trading Analytics System

This project predicts silver commodity prices using time-series, machine-learning, and deep-learning models.

## Models Used

- ARIMA
- XGBoost
- LSTM
- Ensemble Model

## Model Performance

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| ARIMA | 6.24 | 7.48 | -1.790 |
| XGBoost | 1.76 | 2.30 | 0.742 |
| LSTM | 1.23 | 1.57 | 0.886 |
| Ensemble | 1.04 | 1.31 | 0.835 |

## Features Used

- Open, High, Low, and Close prices
- VWAP
- Futures prices
- CPI and interest rates
- Supply-demand indicators
- Market sentiment variables

## Dashboard

The Power BI dashboard provides forecast analytics, model comparison, market-volatility monitoring, trading signals, and portfolio-performance tracking.

## Tools and Technologies

Python, Pandas, NumPy, ARIMA, XGBoost, LSTM, Power BI, and DAX.
